Admin Guide

Mukta Kala

This page explains how to add, remove, and manage artworks in your gallery. The gallery reads from a simple data.json file - no database needed!

File Structure

mukta-kala/
  index.html — Public gallery (visitors see this)
  admin.html — This admin guide
  data.json — Artwork database (edit this!)
  images/ — All your artwork images
    painting1.jpg
    sketch2.png
    ...

How to Add Artwork

  1. Put your image file in the images/ folder (e.g. images/sunset.jpg)
  2. Open data.json in any text editor (or on GitHub directly)
  3. Add a new entry to the "artworks" array (see generator below)
  4. Save and commit/push to GitHub. Done! Gallery updates automatically.

                Tip: To remove an artwork, just delete its entry from the array and remove the image file. To reorder, rearrange the entries in the array.
